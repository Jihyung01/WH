# WhereHere — 기능 명세서 (Feature & Settings Spec)

> 만화풍 잉크 톤의 위치 기반 소셜·탐험 앱. 본 문서는 현재 프로토타입(`WhereHere Manga.html`)에 구현된 모든 화면·기능·설정값을 AI 엔지니어가 실제 앱으로 구현할 수 있도록 정리한 사양서입니다.

---

## 0. 글로벌 / 공통 시스템

### 0.1 디자인 토큰

- **컬러**
  - `--ink #1A1612` (잉크 외곽선/타이포)
  - `--paper #FFFAEB` (배경 종이톤)
  - `--r #FF4757` (메인 레드 / 강조 / FAB)
  - `--y #FFD93D` (옐로우 / 스탬프 / 액션)
  - `--g #3DDC97` (그린 / 성공 / 같이가기)
  - `--b #4FBDFF` (블루 / 정보)
  - `--p #C5A6FF` (퍼플 / 친구 액센트)
- **선·그림자**: 잉크 외곽선 2.5px, hard-shadow `4px 4px 0 var(--ink)` (만화 톤 핵심)
- **라운드**: 카드 11~16px, 칩 5~8px
- **타이포**: 본문 Pretendard, 큰 숫자/제목 `Bagel Fat One`
- **모션**: 버튼 active 시 `translate(2px,2px)` + 그림자 0 (도장 누르는 느낌)

### 0.2 글로벌 컴포넌트

| 컴포넌트 | 용도 | 트리거 |
|---|---|---|
| `Toast` | 모든 액션 피드백 (2.4초) | 모든 `onclick` 액션 |
| `BottomTabBar` | 5탭 전환 | 지도 / 피드 / 소셜 / 캐릭터 / 프로필 |
| `Avatar (av)` | 친구 식별 원형 아이콘 | 이름 첫 글자 + 컬러 |

### 0.3 인증/사용자

- 닉네임, 한글 첫 글자 기반 아바타 컬러 자동 배정
- 레벨/EXP 시스템 (캐릭터·챌린지에서 갱신)
- 위치 권한 필수 (앱 진입 시 요청)

## 1. 지도 탭 (Map)

### 1.1 화면 구성

- **베이스 지도**: Leaflet + OpenStreetMap 타일 (만화풍 페이퍼톤 필터 오버레이)
- **상단 검색바** "오늘 어디로?!" + 알림 종 (배지: 미확인 알림 수)
- **날씨 칩**(좌상단): 현재 위치 날씨 아이콘 + 기온 → 탭 시 사이클(데모 토글)
- **우상단 FAB**: 레이어 필터 (카페/식당/공원/관광 등 카테고리 토글)
- **우하단 FAB 스택**:
  - ✏️ **이벤트 만들기** — 친구 모임/번개 만들기 (장소·시간·참여자)
  - 👣 **흔적 만들기** — 현 위치에 메모/사진 흔적 남김 (캐릭터 도감과 연동)
  - 📍 **내 위치** — 현재 GPS로 카메라 이동
- **하단**: 글로벌 BottomTabBar

### 1.2 마커/오버레이

- **내 위치 핀** (펄스 애니메이션 + 캐릭터 아바타)
- **친구 핀** — 실시간 위치 공유 ON인 친구만 (고스트 OFF인 친구는 표시 X)
- **장소 핀** — 좋아요/방문/흔적 핀 (카테고리별 색상)
- **포그 오브 워(Fog of War)** — 미방문 영역 흐림 처리, 방문 시 점진적 클리어
- **POW(만화 효과)** — 새 장소 발견 시 화면 중앙에 만화 효과음 SVG 노출 (1.6초)

### 1.3 기능

| 기능 | 동작 | 데이터 |
|---|---|---|
| 지도 패닝/줌 | Leaflet 기본 제스처 | viewport state |
| 카테고리 필터 | 다중 선택 토글 | `categories[]` |
| 날씨 표시 | 위치 기반 OpenWeather API | `temp, condition, icon` |
| 흔적 남기기 | 사진+메모+감정태그 → 지도 핀 추가 | `location, photo, memo, emotion, timestamp` |
| 이벤트 만들기 | 장소·시간·참여친구 선택 → 푸시 발송 | `event_id, host, place, time, invitees[]` |
| 새 장소 발견 | 미탐색 좌표 도착 → POW + EXP +20 | `discovered_places[]` |

### 1.4 설정

- 위치 정확도 (정밀/대략)
- 포그 오브 워 ON/OFF
- 친구 위치 공유 받기 ON/OFF
- 날씨 표시 ON/OFF
- 지도 톤 (페이퍼/다크/위성)

## 2. 피드 탭 (Feed)

### 2.1 화면 구성

- **상단 헤더**: 브랜드 필 (W WHEREHERE) + 알림 종
- **세그먼트 탭**: `추천` / `팔로잉`
- **카드 피드** (세로 스크롤)

### 2.2 카드 구성요소

- 작성자 아바타 + 닉네임 + 시간 + 장소 칩
- 메인 이미지 (만화톤 잉크 외곽선 프레임)
- 본문 캡션 (해시태그 자동 링크)
- 액션바: ❤ **좋아요 토글** / 💬 댓글 / 📤 공유 / 🔖 저장
- "이 장소 가기" 칩 → 지도 탭으로 좌표 전달

### 2.3 기능

| 기능 | 동작 |
|---|---|
| 좋아요 토글 | 하트 컬러 채움/해제 + 카운터 ±1 (낙관적 업데이트) |
| 댓글 | 모달/시트 오픈 (대댓글 1단계) |
| 공유 | 친구에게 DM / 외부 공유 |
| 저장 | 프로필 → 장소 메모리에 저장 |
| 무한 스크롤 | 페이지네이션 (20개씩) |
| 신고/숨김 | 카드 우상단 ··· |

### 2.4 설정

- 추천 알고리즘 카테고리 선호 (학습 ON/OFF)
- 차단된 사용자 관리
- 자동 재생 (이미지/비디오)

## 3. 소셜 탭 (Social)

### 3.1 화면 구성 (위→아래)

1. **헤더**: "친구들 👥" + **고스트 토글** (위치 공유 ON/OFF, LED 인디케이터)
2. **스토리 🎬** — 가로 스크롤 (인스타식 링)
3. **레이더 📡** — 동심원 근접 친구 시각화
4. **친구 세그먼트**: 근처 / 온라인 / 전체
5. **친구 리스트** (행 단위)
6. **내 크루 🏆** — 메인 크루 카드
7. **진행 중인 챌린지** — 진행률 바 포함
8. **알림 🔔** — 활동 피드

### 3.2 스토리

- `+` 내 스토리 올리기 (사진 + 24시간 만료)
- 친구 스토리 링 (미시청 = 컬러, 시청완료 = 회색)
- 탭 → 풀스크린 뷰어 (좌우 탭 이동)

### 3.3 레이더

- 4개 동심원 (각 200m / 500m / 1km / 2km)
- 중앙: 내 아바타
- 친구 핀: 컬러 아바타 + 거리 라벨 (m/km)
- 탭 → 친구 프로필 시트

### 3.4 친구 리스트 (frow)

- 아바타 + 닉네임 + 크루 칩 (있을 시) + 위치/상태 라인
- 우측 액션: **만나기** ⚡ / **같이가기** 🚶 / **GHOST** (위치 비공개 시)
- 만나기: 번개 약속 푸시 (15분 내 만남 제안)
- 같이가기: 동행 신청 → 승낙 시 실시간 위치 공유 1시간 ON

### 3.5 크루 카드

- 크루명 + 이모지 + 동네 랭킹 (#3 / 정자동)
- 주간 EXP / 발견 장소 / 멤버 수
- 멤버 아바타 스택 (`+N` 더보기)
- 탭 → 크루룸 진입

### 3.6 챌린지

- 미션 아이콘 + 제목 + 마감/보상 + 진행률 바 + `현재/목표`
- 완료 시 EXP/아이템 보상 → 캐릭터 도감 반영

### 3.7 알림

- 친구 활동: 새 장소 발견 / 흔적 남김 / 챌린지 완료 / 좋아요 / 친구 추가
- 미확인은 `new` 표시 (붉은 도트)

### 3.8 설정

- 고스트 모드 (전체 위치 비공개)
- 위치 공유 친구 화이트리스트
- 알림 카테고리 (장소/좋아요/친구추가/챌린지)
- 스토리 공개 범위 (전체/친구/크루)

## 4. 캐릭터 탭 (Character) — 드레스업 룸

### 4.1 화면 구성

- **무대(스테이지)**: 캐릭터 풀바디 + 만화톤 배경 + 레벨 라벨
- **6개 슬롯**: 모자 / 얼굴 / 상의 / 가방 / 신발 / 펫
- **최근 획득** 가로 스크롤 (NEW 뱃지)
- **하단 액션**: 저장 / 룩북 공유 / 상점 가기

### 4.2 기능

| 기능 | 동작 |
|---|---|
| 슬롯 탭 | 해당 카테고리 인벤토리 시트 오픈 |
| 아이템 적용 | 캐릭터 미리보기 즉시 반영 |
| 저장 | 코디 슬롯에 저장 (최대 3개 룩북) |
| 룩북 공유 | 피드/스토리에 코디 카드 게시 |
| 도감 진입 | 47/120 진행률 표시, 미획득은 실루엣 |
| 상점 | 시즌 배너 + 추천(NEW/할인) + 룩북 둘러보기 |

### 4.3 데이터 모델

```
Character { level, exp, equipped: { hat, face, top, bag, shoes, pet } }
Item { id, category, name, rarity (NORMAL/RARE/EVENT), source (탐험/챌린지/상점), owned: boolean }
Lookbook { id, slots[], coverImage, public: boolean }
```

### 4.4 설정

- 캐릭터 닉네임 / 색상 톤
- 도감 정렬 (획득순/희귀도/카테고리)
- 룩북 공개 범위

## 5. 프로필 탭 (Profile) — 나의 탐험

### 5.1 화면 구성 (위→아래)

1. **헤더**: "나의 탐험" + ⚙ 설정
2. **장소 메모리 📸** (최상단)
3. **탐험 일기장 📓** (신규)
4. **탐험 요약** — 통계 4종
5. **탐험 그래프** — 주/월/연 토글 막대그래프
6. **AI 탐험 노트** — 취향 분석 카드
7. **탐험 허브** — 보조 메뉴 그리드

### 5.2 장소 메모리

- 폴라로이드 카드 가로 스크롤
- 첫 칸: `+ 새 메모리` 추가 슬롯 (사진 + 장소 등록)
- 카드: 그라디언트 이미지 + 이모지 + 제목 + 날짜
- 탭 → 메모리 상세 (사진 갤러리 + 함께한 친구 + 지도 위치)
- "최근 추가 ›" → 전체 갤러리

### 5.3 탐험 일기장 ⭐ NEW

- **카드 구성**: 황색 날짜 스탬프(일/월) + 모눈 노트 카드 본문
  - 제목 + 공개범위 뱃지 (🌍 전체공개 / 👥 친구만 / 🔒 비공개)
  - 본문 인용문 (Courier 손글씨톤)
  - 칩렛: 📍 장소 / ❤ N / 💬 N / 📤 공유 / 🌍 공개로 전환(비공개일 때)
  - **함께** 한 친구 미니 아바타 스택
- **신규 작성**: 우상단 `＋ 새 일기` 버튼 → 작성 시트
  - 제목 / 본문 / 장소 태그 / 공개 범위 / 함께한 친구 멘션 / 사진 첨부
- **공유 액션**: 친구에게 DM 전송 (선택 친구에게만 노출)
- **잠금 카드**: 비공개 일기는 베이지 배경 + 자물쇠 표시

### 5.4 탐험 요약 (Stats)

- 탐험 장소 / 도시 / 기록 / 수집품 (4 KPI)

### 5.5 탐험 그래프

- 토글: 주 / 월 / 연
- 현재 기간 막대 강조 (붉은색 + 라벨)

### 5.6 AI 탐험 노트

- "당신은 [취향]을 좋아해요. 최근에는 [카테고리]를 자주 찾았어요."
- 우측 만화풍 로봇 SVG 일러스트
- 탭 → AI 추천 장소 리스트로 이동

### 5.7 탐험 허브 (Hub Tiles)

- 📔 탐험 일지 / 🗺 내 지도 / 🏆 업적 / 💎 수집품 / 🎯 챌린지 기록 / 📊 분석

### 5.8 설정 (⚙)

- 계정 / 알림 / 위치 / 데이터 / 차단 / 약관 / 로그아웃
- 일기/메모리 백업 (클라우드 동기화)

## 8. 화면 간 네비게이션

- 지도 핀 → 장소 상세 (피드 모음 + 메모리 작성)
- 피드 카드 "이 장소 가기" → 지도 카메라 이동
- 소셜 친구 탭 → 친구 프로필 시트 → DM/같이가기
- 프로필 메모리 → 지도 위치 + 일기장 카드
- 일기장 공유 → 메시지 → 친구 알림

## 9. 핵심 인터랙션 / 모션

- 만화톤 hard-shadow 버튼 prsesed 상태 (translate 2px)
- POW 효과 (장소 발견 / 챌린지 클리어 / 레벨업)
- 토스트는 종이 칩 형태 + 별 아이콘
- 레이더 동심원 ping 애니메이션 (3초 루프)
- 스토리 링 그라디언트 회전

## 11. 향후 확장 후보

- AR 흔적 (카메라 오버레이)

- 다국어 (한/영/일)
